# AGENTS.md — saburou-nvim

Neovim 0.12+ configuration written in Lua. Entry point: `init.lua`.

## Architecture

| Directory | Purpose |
|-----------|---------|
| `init.lua` | Entrypoint — loads globals, user config, lazy.nvim, then `:Luarc` command |
| `lua/hzsr/` | Personal utility library (exposed as `_G.hzsr`). Helpers for async, buffers, editor, tables, windows, etc. |
| `lua/sabunv/` | This config's library (exposed as `_G.sabunv`). Theme integrations, terminals, restart/session, utilities |
| `lua/user/` | User configuration — `opts.lua` (vim options + diagnostics), `cfg.lua` (keymaps + autocmds) |
| `lua/lzy/` | lazy.nvim plugin specs. `plg.lua` imports all; each `l_*.lua` configures one plugin |

## Key conventions

- **Leader**: space (` `). Local leader also space.
- **Indentation**: 2 spaces, `expandtab` everywhere.
- **Plugin spec pattern**: `lua/lzy/l_<plugin>.lua` exports a `setup()` function; `plg.lua` wires it via `config = function() require("lzy.l_<plugin>").setup() end`.
- **Globals**: `_G.hzsr` and `_G.sabunv` are set in their respective `init.lua` files. Code outside these modules accesses them as globals.
- **Comments**: Spanish throughout. Match this style.

## First-run setup

After cloning to `~/.config/nvim` (or `~/.config/$NVIM_APPNAME`):

```vim
:Lazy sync
:MasonInstallAll
:TSInstallAll
```

Mason package list lives in `lua/hzsr/mason/nvchad/` (adapted from NvChad, GPL-3.0).

## Theme

Uses `bluz71/vim-moonfly-colors`. Custom integrations for lualine, bufferline, nvim-tree, statuscol, and render-markdown are in `sabunv.moonfly`.

## Notable quirks

- `lazy-lock.json` is gitignored — do not commit it.
- `.luarc.json` is generated by the `:Luarc` command and gitignored.
- No CI, linter (selene), or formatter (stylua) config exists at repo level.
- `user/cfg.lua` line 74-75: custom `ñ`/`Ñ` mappings for appending lines (Spanish keyboard).
